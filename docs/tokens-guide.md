# 品詞分解データ（`data/tokens/*.js`）作成ガイド

教科書教材（`data/passages.js` の 20 編・65 段落）の**原文全文に品詞分解を付ける**ための仕様書です。
これができると、文章ページの「原文と現代語訳」で**原文のどの語をタップしても品詞・活用・語義が出る**ようになり、
別枠になっていた「例文（品詞分解つき）」は要らなくなります。

このファイルを読めば、担当した文章のデータを一人で最後まで作れるように書いてあります。
**迷ったら「見本」（`data/tokens/makura-haru.js` / `data/tokens/tsurezure-jo.js`）と同じ書き方にしてください。**

---

## 0. 3 行でいうと

1. `data/tokens/<passageId>.js` を 1 文章 1 ファイルで作る。
2. `passages.js` の `paragraphs[i].text` を語に割り、**割った `s` を全部つなげると原文と一字一句同じ**になるようにする。
3. `node tools/validate-tokens.mjs` を実行して **エラー 0** にする。

---

## 1. データの置き場所と形

### ファイル

```
data/tokens/<passageId>.js      文章 1 編 = 1 ファイル
```

`<passageId>` は `data/passages.js` の `id` そのまま（例 `makura-haru`, `ise-akutagawa`）。
**ファイル名と `window.KOBUN.tokens` のキーは必ず一致させること。**

- 文字コードは **UTF-8（BOM なし）**、改行は **LF**。
- `data/*.js` と同じく「`window.KOBUN` に代入するだけ」のスクリプト。`import` / `export` は使わない（`file://` で動かすため）。

### 雛形

新しい文章を作るときは、これをコピーして中身を差し替えてください。

```js
/* =====================================================================
 * data/tokens/<passageId>.js — 文章「<title>」（<作品名> <section>）の品詞分解
 * ---------------------------------------------------------------------
 * 段落ごとの配列。tokens[i] が passages.js の paragraphs[i] に対応する。
 * 各トークンのキーの意味と書き方は **docs/tokens-guide.md** を読むこと。
 *   s 表層形（原文の字面そのまま） / b 基本形 / p 品詞 / c 活用の種類 /
 *   f 活用形 / m 語義・用法 / w 330 語の wordId / n 注記
 * 段落内の s を全部つなげると paragraphs[i].text と一字一句一致する
 * （tools/validate-tokens.mjs が検査する）。
 *
 * 出典・校閲: <どの本文に拠ったか。自信のない箇所は各トークンの n に「要確認」と書く>
 * ===================================================================== */
window.KOBUN = window.KOBUN || {};
window.KOBUN.tokens = window.KOBUN.tokens || {};
window.KOBUN.tokens['<passageId>'] = [
  [ // 段落 1　<原文の冒頭 10 字ほど>…
    { s: '春', b: '春', p: '名詞', m: '春' },
    { s: 'は', b: 'は', p: '係助詞', m: '（主題）〜は' },
    { s: '。', p: '記号' },
  ],
  [ // 段落 2　…
  ],
];
```

- 配列の**外側の要素が段落**、内側の要素が 1 語（トークン）。
- **段落数は `passages.js` の `paragraphs.length` と必ず同じ**にする（段落を勝手に増減しない）。
- 1 行 1 トークン。キーの順番は **`s` → `b` → `p` → `c` → `f` → `m` → `w` → `n`** で揃える。

## 2. トークンのキー

| キー | 必須 | 意味 | 例 |
|---|---|---|---|
| `s` | ○ | **表層形**。原文の字面そのまま（活用した形・音便の形のまま、漢字も原文どおり） | `'近う'` `'たまへ'` `'。'` |
| `b` | ○（記号は不要） | **基本形**。用言・助動詞は終止形。活用しない語は `s` と同じでよい | `'近し'` `'たまふ'` |
| `p` | ○ | **品詞**。§3 の統一ラベル表から選ぶ | `'形容詞'` `'係助詞'` |
| `c` | 活用語のみ | **活用の種類**。§4 参照。活用しない語は書かない | `'ハ行四段'` `'ク活用'` `'ラ変'` |
| `f` | 活用語のみ | **活用形**。`未然形` `連用形` `終止形` `連体形` `已然形` `命令形` の 6 つだけ | `'連用形'` |
| `m` | ○（記号は不要） | **この文脈での語義**。助詞・助動詞は用法を `（　）` で頭に付ける | `'たいそう'` `'（主題）〜は'` `'（打消）〜ない'` |
| `w` | 該当語のみ | **330 語の `wordId`**（`data/words.js` の `id`、数値）。§5 参照 | `99` |
| `n` | 任意 | **注記**。音便・係り結び・諸説・複合語の説明など。自信がなければ**必ず「要確認：…」と書く** | `'「近く」のウ音便。'` |

### 書き方の決まり

- **`s` は原文をいじらない。** 旧字・仮名遣い・漢字表記をそのまま写す。ここを直すと検証が落ちる。
- **句読点・記号も 1 トークン**にする。形は `{ s: '。', p: '記号' }`（`b` `m` は付けない）。
  対象は `。` `、` `「` `」` `『` `』` `・` `／` など。**「（中略）」も丸ごと 1 記号トークン**にする
  → `{ s: '（中略）', p: '記号' }`。
- **`f` に音便や係り結びを書かない。** `'連用形（ウ音便）'` は不可。`f: '連用形'` とし、`n: '「近く」のウ音便。'` と書く。
- **`m` は言い切りの短文**にする。長い説明は `n` へ。
- `n` に `要確認` の 3 字が入っていると、アプリの表示と検証出力で目立つ印が付く。**推測で書いた箇所には必ず入れる。**

### いちばん大事な決まり

> **段落内の `s` を順に全部つなげた文字列が、`passages.js` の `paragraphs[i].text` と一字一句一致すること。**

`tools/validate-tokens.mjs` はこれを最優先で見ます。ずれていると
「何文字目から食い違ったか」と前後の文字列を表示するので、そこを直してください。

## 3. 品詞の統一ラベル表（`p`）

**この 19 個以外は使わない。**

| 分類 | ラベル |
|---|---|
| 体言 | `名詞` `代名詞` |
| 用言 | `動詞` `形容詞` `形容動詞` |
| その他の自立語 | `副詞` `連体詞` `接続詞` `感動詞` |
| 付属語 | `助動詞` |
| 助詞 | `格助詞` `係助詞` `副助詞` `接続助詞` `終助詞` `間投助詞` |
| 語の一部 | `接頭語` `接尾語` |
| 記号 | `記号` |

### 迷いやすいものの割り当て

- **数詞**（`三つ` `一寸`）→ `名詞`。`n: '数詞。'` と添える。
- **固有名詞**（`奈良` `芥川`）→ `名詞`。`n: '固有名詞。'` と添える。
- **敬語**（`たまふ` `おはす` `まうす`）→ **品詞は `動詞` のまま**。敬意の種類は `m` に付ける。
  → `{ s: 'たまひ', b: 'たまふ', p: '動詞', c: 'ハ行四段', f: '連用形', m: '（尊敬）お〜になる', w: 72 }`
  用法の書き分けは `（尊敬）` `（謙譲）` `（丁寧）`。補助動詞なら `m: '（尊敬）〜なさる'` のように「〜」を入れる。
- **補助動詞**（`〜てあり` の `あり`、`はべり`）→ `動詞`。`n: '補助動詞。'` と添える。
- **接頭語 / 接尾語** は、切り離して意味が説明できるときだけ分ける。
  `うち光り` のように一語として扱うほうが自然なら 1 トークンにし、`n` で「うちは接頭語」と説明する。
  一方 `あやしがり` の `がり` のように活用して別の語をつくるものは、
  `{ s: 'あやし', ... p: '形容詞' }` + `{ s: 'がり', b: 'がる', p: '接尾語', ... }` のように**分けてよい**。
  **どちらでもよいときは分けない**（`w` を付けやすいほうを優先）。
- `かな` `や` `よ` `ぞかし` → `終助詞`。`を` `や` が文中で調子をとるだけなら `間投助詞`。

## 4. 活用の種類（`c`）と活用形（`f`）

`c` は品詞ごとに書き方が決まっています。**この表にある値以外はエラーになります。**

| 品詞 | `c` の書き方 | 例 |
|---|---|---|
| 動詞（正格） | **行＋種類**。行は `ア行`〜`ワ行`、種類は `四段` `上一段` `上二段` `下一段` `下二段` | `ハ行四段` `ヤ行下二段` `マ行上一段` |
| 動詞（変格） | **行を書かず 2 字**で | `カ変` `サ変` `ナ変` `ラ変` |
| 形容詞 | | `ク活用` `シク活用` |
| 形容動詞 | | `ナリ活用` `タリ活用` |
| 助動詞 | **活用の型**（「〜型」を付ける） | `四段型` `上二段型` `下二段型` `ラ変型` `ナ変型` `サ変型` `形容詞型` `形容動詞型` `特殊型` `無変化型` |
| 上記以外 | **書かない**（名詞・副詞・助詞・接続詞・感動詞・連体詞・記号など） | — |

`f` は **`未然形` `連用形` `終止形` `連体形` `已然形` `命令形` の 6 つだけ**。
音便・係り結び・撥音便無表記などの補足は **`n`** に書きます。

### よく使う助動詞の `c`（迷ったらここを見る）

| 助動詞 | `c` | 助動詞 | `c` |
|---|---|---|---|
| `る` `らる` `す` `さす` `しむ` `つ` | `下二段型` | `む` `らむ` `けむ` `むず`※ | `四段型` |
| `ず` `き` `まし` | `特殊型` | `じ` `らし` | `無変化型` |
| `べし` `まじ` `ごとし` `たし` | `形容詞型` | `なり`（断定） `たり`（断定） | `形容動詞型` |
| `けり` `たり`（完了・存続） `り` `めり` `なり`（伝聞推定） | `ラ変型` | `ぬ`（完了） | `ナ変型` |

※ `むず` は `サ変型`（`ず` 型）とする流儀もあるが、このアプリでは `サ変型` を使う。

## 5. 330 語との対応（`w`）

- `data/words.js` の **`headwords`（または `kanji` の各表記）と `b` が一致する語には必ず `w` を付ける。**
- **判定は基本形（`b`）で行う。** 活用形・音便形でも、基本形が見出し語なら付ける。
  例：`s: 'うつくしう'` / `b: 'うつくし'` → `w: 10`。
- `w` を付けたトークンは、文章ページで**実線の下線**になり、タップすると単語詳細ページへのリンクが出ます。
  また単語詳細ページの「この語が出てくる文章」にこの段落が並びます。**付け忘れると語と文章がつながりません。**

### 同形異語は語義で選ぶ

同じ字面で別語のものがあります。**文脈の意味で判断し、違う語なら `w` を付けず、`n` に理由を書く**（`n` を書けば検証の警告も消えます）。

| 字面 | 選択肢 | 選び方 |
|---|---|---|
| `ながむ` | `53`〔眺む〕もの思いにふける／`54`〔詠む〕詩歌を吟じる・作る | **どちらも 330 語。** 語義で選ぶ |
| `ゐる` | `61`〔居る〕座る・とどまる／`181`〔率る〕引き連れる | **どちらも 330 語。** 語義で選ぶ |
| `よし` | `34` 形容詞〔良し〕よい／`97` 名詞〔由〕理由・縁／`330`〔縦し〕たとえ〜でも | 品詞と語義で選ぶ |
| `なる` | `283`〔馴る〕慣れ親しむ・着慣れる | 〔成る〕＝〜になる（ラ行四段）なら **`w` なし ＋ `n` に理由** |
| `おこす` | `158`〔遣す〕よこす・送ってくる | 〔起こす〕＝火をおこす なら **`w` なし ＋ `n` に理由** |
| `など` | `108` 副詞「などか／など」＝どうして | 副助詞「など」＝〜など なら **`w` なし**（品詞が違うので検証も黙る） |
| `たまふ` | `72`〔給ふ〕 | 四段なら尊敬、下二段なら謙譲。`c` と `m` で書き分ける |

同じ字面で 330 語に 2 件あるものは、検証器が `w: 53 または 54` のように**両方の id を出します**。
**語義で選んでください。**

### 呼応の副詞（`え〜ず` `な〜そ` `さらに〜ず` など）

`w` は**副詞側のトークンだけ**に付けます（`headwords` も `え` `な` `さらに` だけになっています）。
打消の `ず` `じ` `まじ` `で` や禁止の `そ` には `w` を付けず、`n` に「『え』と呼応して不可能」と書きます。

### 複合語

`よしなし事`（＝`よしなし` ＋ `事`）のように、330 語を含む複合語を 1 トークンにしたときは、
`b` を複合語のまま（`'よしなし事'`）にし、`w` は含まれる語の id を付け、**`n` に複合語であることを書く**。

### 形容動詞の語幹用法

`あはれ` `つれづれ` `おぼろけ` `そぞろ` `等閑` のように、形容動詞の**語幹だけ**が
名詞のように使われることがある。このときは

- `p: '名詞'`（語幹用法であることを `n` に書く）
- `b` は語幹のまま（`'あはれ'`。見出し語の `'あはれなり'` にしない）
- `w` は形容動詞の id をそのまま付けてよい

検証器は「見出し語 − なり／たり ＝ `b`」の形を語幹用法と認めて黙るので、警告は出ない。

### 検証で残ってよい警告

`b` が見出し形と一致しない旨の警告は、次の場合は**意図的なので残してよい**（`n` に理由を書く）。

- 異形を採った（源氏の `まして` に `まいて`(219) を付けるなど）
- 見出し語が連体形（`ふる`）で、本文は終止形（`ふ`）
- 逆に、**心当たりが無いのに出た警告は取り違えを疑う**こと。

## 6. 高校古典文法の定番論点の扱い

**アプリの目的は「タップしたら学校文法の答えが出る」ことなので、識別の結論を `m` と `c` / `f` に必ず出す。**

### 「なり」— 断定 / 伝聞推定 / 動詞 / 形容動詞の一部

| 何か | 書き方 |
|---|---|
| 断定の助動詞 | `{ s: 'なり', b: 'なり', p: '助動詞', c: '形容動詞型', f: '終止形', m: '（断定）〜である' }` |
| 伝聞推定の助動詞 | `{ s: 'なり', b: 'なり', p: '助動詞', c: 'ラ変型', f: '終止形', m: '（伝聞推定）〜だそうだ・〜のようだ' }` |
| 動詞〔成る〕 | `{ s: 'なり', b: 'なる', p: '動詞', c: 'ラ行四段', f: '連用形', m: '〜になる' }` |
| 形容動詞の語尾 | 語幹と切らず 1 トークン。`{ s: 'あはれなり', b: 'あはれなり', p: '形容動詞', c: 'ナリ活用', f: '終止形', … }` |

※ 断定は体言・連体形に、伝聞推定は終止形（ラ変は連体形）に付く。判別は `c` の違いにも出るので**両方書く**。

### 「ぬ」「ね」— 完了 / 打消

| 何か | 書き方 |
|---|---|
| 完了の助動詞「ぬ」終止形 | `{ s: 'ぬ', b: 'ぬ', p: '助動詞', c: 'ナ変型', f: '終止形', m: '（完了）〜てしまった' }` |
| 打消の助動詞「ず」連体形 | `{ s: 'ぬ', b: 'ず', p: '助動詞', c: '特殊型', f: '連体形', m: '（打消）〜ない' }` |
| 完了「ぬ」命令形 | `{ s: 'ね', b: 'ぬ', p: '助動詞', c: 'ナ変型', f: '命令形', m: '（完了）〜てしまえ' }` |
| 打消「ず」已然形 | `{ s: 'ね', b: 'ず', p: '助動詞', c: '特殊型', f: '已然形', m: '（打消）〜ない' }` |

**`b` と `c` と `f` の 3 つが揃って初めて識別が伝わる。省略しないこと。**

### 「に」— 6 通り

| 何か | 書き方 |
|---|---|
| 格助詞 | `{ s: 'に', b: 'に', p: '格助詞', m: '（場所）〜に' }`（用法は `場所` `時` `対象` `目的` `原因` `帰着点` `変化の結果` から選ぶ） |
| 断定の助動詞「なり」連用形 | `{ s: 'に', b: 'なり', p: '助動詞', c: '形容動詞型', f: '連用形', m: '（断定）〜で' }` |
| 完了の助動詞「ぬ」連用形 | `{ s: 'に', b: 'ぬ', p: '助動詞', c: 'ナ変型', f: '連用形', m: '（完了）〜てしまっ（た）' }` |
| 形容動詞の連用形の語尾 | 語幹と切らず 1 トークン。`{ s: 'ほのかに', b: 'ほのかなり', p: '形容動詞', c: 'ナリ活用', f: '連用形', … }` |
| 接続助詞 | `{ s: 'に', b: 'に', p: '接続助詞', m: '（逆接）〜のに' }`（`単純接続` `順接` `逆接`） |
| 副詞の一部 | 切らずに副詞 1 トークン（`げに` `つひに` など） |

※ **連体形＋「に」は諸説ある。** このアプリでは「〜ときに」と時を示す場合は `格助詞`（`m: '（時）〜ときに'`）とし、
`n: '諸説: 連体形＋「に」を接続助詞（単純接続）とみる注釈もある。'` を添える（見本 `makura-haru` 段落 3・4 参照）。

### 「る」「れ」— 受身・尊敬・自発・可能 / 完了「り」

助動詞「る」「らる」は `m` に **`（受身）` `（尊敬）` `（自発）` `（可能）`** のどれかを必ず書く。
完了・存続の「り」は `b: 'り'`, `c: 'ラ変型'`。

### 「なむ」— 4 通り

| 何か | 書き方 |
|---|---|
| 係助詞（強意） | `{ s: 'なむ', b: 'なむ', p: '係助詞', m: '（強意）〜こそ', n: '係り結び。結びは連体形。' }` |
| 終助詞（他への願望） | `{ s: 'なむ', b: 'なむ', p: '終助詞', m: '（願望）〜てほしい' }` |
| 完了「ぬ」未然形＋推量「む」 | `な`（`b: 'ぬ'`, `f: '未然形'`）と `む` の**2 トークンに分ける** |
| ナ変動詞の未然形＋「む」 | 動詞と `む` の 2 トークンに分ける |

### 係り結び

- 係助詞（`ぞ` `なむ` `や` `か` `こそ`）の `n` に `'係り結び。結びは連体形。'` / `'…已然形。'` と書く。
- 結びの語の `n` に `'「こそ」の結び。'` と書く（見本 `tsurezure-jo` 参照）。

### 音便

`s` は音便の形のまま。`f` は音便前の活用形（`連用形` など）。`n` に `'「近く」→「近う」のウ音便。'` と書く。
撥音便無表記（`あんなり` → `あなり`）も `n` に明記。

### 「し」「しか」

過去の助動詞「き」の連体形 `し` / 已然形 `しか` は `b: 'き'`, `c: '特殊型'`。
副助詞の `し`（強意）、サ変「す」の連用形 `し`、形容詞の語尾 `し` と紛れるので、必ず `p` と `b` で区別する。

### 「が」「の」

主格・連体修飾・同格・体言の代用（準体格）を `m` の `（　）` で書き分ける。
同格は `m: '（同格）〜で'`、準体格は `m: '（準体格）〜のもの'`。

## 8. `passages.js` の `vocab` との関係

文章ページでは、`vocab` の語が原文の上でハイライトされます（実線＝330 語、点線＝文章固有語）。
これを**トークンの上に重ねる**ので、`vocab[].surface` が**トークンの切れ目に沿って切り出せる**必要があります。

- 検証器 (f) が、沿っていない箇所を警告します。
- 例：`vocab` に `渡る` があるのにトークンが `もて渡る` 1 語だと、ハイライトが語を割ってしまう。
- 直し方は 2 通り。**原則はトークンの切り方を優先**し、`passages.js` 側の `surface` を語のまとまりに直す。
  トークンの切り方が不自然になるなら、逆にトークンを分ける。
- ただし `passages.js` の `vocab` の**並び順は変えないこと**（文章固有語の学習履歴のキーが `p:<passageId>:<添字>` なので、
  途中に挿入すると履歴がずれる）。`surface` の文字列を直すだけなら安全。
- 実際に直した例（すべて `passages.js` の `surface` だけを変更）
  - `tsurezure-jo` `よしなし` → `よしなし事`／`makura-utsukushiki` `うつくし` → `うつくしき`、
    `をかしげ` → `をかしげなる`／`makura-chunagon` `いみじ` → `いみじき`／
    `sarashina-kadode` `ゆかし` → `ゆかしさ`
  - 逆にトークンを分けた例：`makura-haru` の `もて渡る` を
    接頭語 `もて` ＋ 動詞 `渡る`(w:59) の 2 トークンにした（重要語が見えるようになる）

`w` を付けたトークンは自動的に実線扱いになるので、`vocab` に無い 330 語でもタップで詳細へ飛べます。

### よくあるエラーと直し方

| メッセージ | 原因 |
|---|---|
| `s を連結した文字列が原文と一致しません` | 字を落とした／増やした／別字を使った。表示される「N 文字目」の前後を見る |
| `c="ラ行変格" は活用の種類の表にありません` | `ラ変` と書く（`カ変` `サ変` `ナ変` も同様） |
| `f="連用形（ウ音便）" は活用形の表にありません` | `f: '連用形'` にし、音便は `n` へ |
| `p="動詞" は活用するので f を書いてください` | 活用語には `c` と `f` の両方を書く |
| `b="…" が w=… の見出し形と一致しません` | `w` の付け間違い（同形異語）か `b` の書き間違い |
| `passageId "…" を上書きしています` | 2 つのファイルが同じキーに代入している |

## 10. 作業の手順（1 文章あたり）

1. `data/passages.js` から担当の文章を開き、`paragraphs[].text` と `translation`、`vocab`、`note` を読む。

  この仕様書に先に固めたので、3 人が書いても表記が揃いました。

新しい教材を足すときも、**1 文章 = 1 ファイル**と**この仕様書**の 2 つを守れば同じように進められます。
