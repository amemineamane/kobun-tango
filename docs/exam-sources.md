# 大学入学共通テスト・センター試験（国語・古文）の出典

調査日: 2026-09-11 ／ 対象: センター試験 2016〜2020 年度・大学入学共通テスト 2021〜2026 年度

## 0. 方針

- 載せるのは **出典作品の原文そのもの**（著作権保護期間が満了しているもの）と、
  このアプリのために書き下ろした現代語訳だけ。
  **試験の設問・注・リード文・予備校の訳は載せない**（大学入試センターや各社の著作物）。
- 出典は **複数の独立したソースで一致したものだけを「確定」**とする。
  1 ソースでしか確認できなかったものは「未確認」と明記し、`data/works.js` には登録していない。
- 本文は **信頼できる翻刻が web 上で確認できるものだけ**に入れる。
  確認できなかった作品は `data/works.js` に作品情報だけ登録し、`summary` に出題年と場面の概要を書いた。
- 本文を入れた作品でも、**試験の抜粋範囲と一致させる必要はない**。
  場面として読める範囲を取り、省いた箇所は本文中に `（中略）` と書いた。

## 4. 本文が確認できなかった理由

Wikisource（日本語版）と やたナビTEXT を全文検索し、次のように判定した。

- **Wikisource にページはあるが本文が入っていない**: 蜻蛉日記（`蜻蛉日記 (國文大觀)` は
  Commons のスキャンを `<pages>` で取り込む形で、Page 名前空間が未校正のため本文が空）。
  今鏡・大鏡は `今鏡 (今鏡読本)` `増鏡 (校註増鏡)` のように本文入りの版が別にある。
- **Wikisource・やたナビとも項目がない**: 栄花物語・千載和歌集・とりかへばや物語・
  俊頼髄脳・散木奇歌集・石上私淑言・石清水物語・正徹物語・草縁集・在明の別・
  うつほ物語・山路の露・木草物語・玉水物語・小夜衣。
- **J-TEXTS（www.j-texts.com）は調査時点で接続できなかった**（DNS 解決不可）。
  復旧すれば栄花物語・うつほ物語などを再調査する価値がある。
- 国立国会図書館デジタルコレクションや国文学研究資料館の新日本古典籍総合データベースには
  影印（画像）があるが、**翻刻テキストではない**ので本文の典拠には使わなかった。

## 6. 第 2 段階（品詞分解）への引き継ぎ

`data/tokens/<passageId>.js` を 7 本つくる。書き方は `docs/tokens-guide.md`。
段落数を `paragraphs.length` と合わせ、段落内の `s` を連結すると `text` と一字一句一致させること。

### 担当割り案（3 グループ、字数がほぼ均等になるようにした）

|---|---|---|---|

| B | `masukagami-jo`（6 段 / 590 字）、`masukagami-saigu`（5 段 / 687 字） | 11 | 1277 |
| C | `towazu-kuretake`（6 段 / 581 字）、`towazu-saigu`（4 段 / 679 字）、`genji-wakana`（5 段 / 811 字） | 15 | 2071 |

### 注意点（グループ別）

**A｜今昔物語集** — いちばん癖が強い。

- 漢字表記が多く、送り仮名が少ない。`s`（表層形）は原文の字面のまま、
  `b`（基本形）は仮名で書くのがよい（例 `s: '止事無き'` / `b: 'やむごとなし'`）。
- 促音・撥音が表記されない形が続く: `参て`（まゐりて）`思て`（おもひて）`渡て`（わたりて）
  `行て`（ゆきて）`云て`（いひて）。**連用形＋「て」で切る**と決めておくと揺れない。
- 当て字が多い: `和ら`＝やをら、`去来`＝いざ、`早う`＝はや（「なんと」）、
  `奇異`＝あさまし、`怱ぎ`＝いそぎ、`懃ろに`＝ねんごろに、`糸`＝いと。
  `n`（注記）に読みを書いておくと、あとで読む人が助かる。
- 会話文が多い（「〜と云く」「〜と。」の形）。`と` は格助詞、`云く` はク語法。
- `貴気なる` `怖し気なる` `賤気なる` は「〜げなり」（形容動詞ナリ活用）。
- 漢数字・記号（`。` `「` `」`）は `p: '記号'` で 1 トークンにする。

**B｜増鏡** — 和文の王道だが、敬語が二重・三重に重なる。

- `見えさせ給ふ` `入らせ給ふ` `出でさせおはしまして` のような **二重敬語**を、
  トークンに分けて `f`（活用形）を正しく振ること。
- 序に **和歌が 2 首**ある（`愚なる心や見えん増鏡…` / `今もまた昔を書けば増鏡…`）。
  歌は句切れで切らず、通常どおり語単位で切る。掛詞は `n` に書く。
- `思ひ給へわかれぬ` の `給へ` は **下二段（謙譲）**。四段の尊敬と取り違えないこと
  （`c: 'ハ行下二段'`、`f: '連用形'`）。`docs/tokens-guide.md` の「たまふ」の項を参照。
- 踊り字はすでに開いてある（`つきづきしき` `たびたび` `かかりて` `いかが` `かかる`
  `語らひつつ` `ままに`）。原文の `〳〵` を探しても出てこないので注意。
- 装束・儀式の名詞（`御褥` `御佩刀` `葡萄染め` `甘の御衣`）は 1 語として扱ってよい。

**C｜とはずがたり・源氏物語** — 会話文と和歌が多い。

- `towazu-kuretake` には **和歌が 2 首**あり、うち 1 首は本文と地続きに書いてある
  （`…情けなき心地しながら、よそながらなれてはよしや小夜衣いとど袂の朽ちもこそすれ　思ふ心の末、…`）。
  歌のあいだの **全角スペース**も 1 文字なので、`s` に含めるのを忘れないこと
  （`s: '　'` を `p: '記号'` で置くのが安全）。
- `たのむの雁`（「田の面」と「頼む」）、`なれ`（「着馴る」と「馴る」）、
  `小夜衣`（「小夜」と「さ」）など **掛詞が多い**。`n` に書く。
- `towazu-saigu` は **会話文と地の文が入れ替わり立ち替わり**出る。
  語り手（二条）自身の動作に付く `参る` `さぶらふ` は謙譲、院・女院に付く
  `おはします` `仰せ` `御覧ず` は尊敬。主語の取り違えに注意。
- `genji-wakana` は物の怪の長い独白がある。`調ぜられて` `思し惑ふ` `見たてまつれ` など
  **受身・尊敬・謙譲が連続**する。`e 見過ぐさで` の `え` は副詞（呼応）で、
  `で` は打消接続の接続助詞。
- `もののけ` `御修法` `験者` `不動尊` は仏事の語。1 語として扱い、`m` に読みを書く。
