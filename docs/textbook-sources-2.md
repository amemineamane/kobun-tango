## 0. 方針

第 1 次（`docs/verification.md`）と同じ方針を引き継いだ。

- 本文は **教科書で最も一般的な本文**に揃える。
  平家物語＝覚一本系、枕草子＝三巻本、徒然草＝流布本、伊勢物語＝定家本系（嵯峨本の校訂本文で確認）、
  竹取物語＝流布本、大鏡・蜻蛉日記・土佐日記・更級日記＝各翻刻の校訂本文。
- **翻刻が web 上で確認できるものだけを収録**した。確認できなかった候補は §4 に理由を書いた。
- 取得した翻刻テキストと**機械照合**した（照合スクリプトは一時領域に置いた使い捨てのもので、
  本文を文ごとに切り、句読点・振り仮名・旧字体・踊り字・仮名遣い（ゐゑ・づぢ）を正規化して
  出典テキストの中を探し、見つからない文だけを差分表示する）。
  相違はすべて各 passage の `note` に「機械照合の結果…」「底本異同: …」として残した。
- 漢字／仮名の書き分け・送り仮名・句読点・助動詞「ん」を「む」と書くことは**異同として扱わない**（許容）。
  語句そのものが違う箇所だけを異同として記録した。
- **現代語訳はこのアプリのために書き起こした**。教科書・市販の訳文は参照していない。
  照合には各サイトの「原文」だけを取得し、併載されている現代語訳は取得していない。
- 著作権: 収録したのは**保護期間の満了した原文**と、このアプリのために書いた現代語訳だけ。
  校訂に著作権が及びうるテキスト（日本古典文学摘集など）は**照合のためだけに使い、
  そのままの字面（句読点・送り仮名・校訂者の表記選択）は写していない**。
