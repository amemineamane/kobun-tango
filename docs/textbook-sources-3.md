## 0. 方針

今回は「作品数を増やす」ことが目的なので、**既存 30 作品に無い作品を優先**した。
本文の取得元は、[copyright-review.md](copyright-review.md) の結論に従って
**パブリックドメインの翻刻に限った**。

- **採る**: 日本語版 Wikisource のうち、ページに `{{PD-old}}` または
  `{{PD-old-auto-1923}}` が貼られているもの（國文大觀・群書類從・國民文庫・
  國史大系・有朋堂文庫・明治期の刊本）。
- **避ける**: やたナビTEXT の校訂本文（CC BY-SA 4.0）、
  Wikisource『源氏物語 (渋谷栄一校訂)』『小倉百人一首』（CC BY-SA 3.0）、
  日本古典文学摘集（許諾なし）、UVa JTI（複製禁止）。
  第 2 次では やたナビTEXT を 7 編に使ったが、**今回は 1 編も使っていない**。
- 本文は翻刻を機械照合したうえで、**仮名遣い・漢字・句読点・鉤括弧を
  教科書で一般的な形に整えた**。字を変えた箇所は §3 と `passage-notes.md` に残す。
- 現代語訳は書き下ろし。教科書・市販訳・解説サイトの訳は見ていない。

## 4. 和歌のデータ設計

和歌集は**「1 作品 = 1 編、1 首 = 1 段落」**にした。

```
passage { id:'manyo-sen', workId:'manyoshu', section:'教科書定番歌' }
  paragraphs[0] { text: '<歌だけ>',  translation: '<訳>（作者名・巻○）' }
  paragraphs[1] { ... }                       ← 1 首 = 1 段落
  ...
  vocab[] … 8 首ぶんをまとめて 1 本
```

理由:

- **画面を一切変えずに済む。** 文章詳細は `paragraphs[i].text` と `.translation` を
  上下／横並びで対応表示する。1 首 1 段落にすれば、そのまま「歌と訳」の対訳になる。
- **品詞分解が 1 首ずつ書ける。** `data/tokens/<id>.js` は段落ごとの配列なので、
  歌ごとに区切って書け、係り結び・掛詞の注記も歌の中で閉じる。
- **詞書と作者名を本文に混ぜない。** `text` は歌 31 音だけにした。
  作者と巻は `translation` の末尾に **「（作者名・巻○）」** の形で添える。
  こうすると原文側の字面が乱れず、`vocab[].surface` の照合も素直になる。
  詞書が読解に要る歌（古今 406 の阿倍仲麻呂など）は訳の中で事情を補った。
- **`grade`** は万葉・古今を `['中2','高校']`、新古今を `['高校']` とした。
  中学の教科書は万葉・古今・新古今を「和歌三大集」としてまとめて扱うことが多いが、
  新古今の技巧（本歌取り・体言止め）は高校で扱われるので分けた。

選歌（各 8 首）は、底本の歌番号で次のとおり。

- `manyo-sen`: 巻一 20・28・48／巻二 132／巻三 318／巻五 803／巻十四 3373／巻二十 4401
- `kokin-sen`: 巻一 1・2・53／巻二 84・113／巻四 169／巻九 406／巻十二 552
- `shinkokin-sen`: 巻一 1・38／巻四 361・362・363／巻五 518／巻六 671／巻十一 1034

**注意**: `shinkokin-sen` の 361〜363 は「三夕の歌」で、
361 寂蓮・362 西行・363 定家の並びが底本どおり。この順を崩さないこと。
既存の `ise-tsukiya`（月やあらぬ）と `jikkinsho-oeyama`（大江山）に採られた歌は、
重複を避けて選歌から外した。

**和歌は 330 語の当たりが少ない**（`manyo-sen` は 2 語、`shinkokin-sen` は 4 語）。
これはデータの不備ではなく、31 音の歌に古文単語帳の見出し語がそもそも多く出ないため。
文章固有語（枕詞・歌枕・掛詞）を 9〜12 語ずつ入れて学習デッキが成立するようにした。

### 共通の注意

1. **段落内の `s` を連結すると `paragraphs[i].text` と一字一句一致すること**。
   `tools/validate-tokens.mjs` が突き合わせる。
2. **`vocab[].surface` はトークン境界に沿って切れること**（`docs/tokens-guide.md` §8）。
   沿わない場合は**まず `passages.js` の `surface` を語のまとまりに直す**。
   ただし **`vocab` の並び順は変えない**（文章固有語の学習履歴キーが
   `p:<passageId>:<添字>` なので、途中に挿入すると履歴がずれる）。
3. **和歌の段落は 1 首まるごと 1 段落**。句切れでトークンを分けない。
   句と句の間に空白を入れない（`text` に空白が無い）。
4. **330 語に当たるトークンには必ず `w` を付ける**。
   `vocab` に入れていない語でも、`w` を付ければ単語詳細へ飛べる（`tokens-guide.md` §8）。
5. 掛詞・枕詞・本歌取り・係り結び・反実仮想は `n`（注記）に書く。
   `m`（語義）には文脈での意味だけを書く。
6. 1 編書いたら `node tools/validate-tokens.mjs` でエラー 0 を確認する。
