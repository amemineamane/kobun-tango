# 古文単語帳アプリ 紹介ショート動画 台本

投稿先：YouTube ショート／TikTok／X（すべて縦 9:16、1080×1920）
対象：中高生・受験生と、その保護者・国語の先生
アプリ：<https://amemineamane.github.io/kobun-tango/>　制作：雨峰あまね

## 0. 事実メモ（この数字以外は言わない）

台本に出てくる数字は `data/*.js` から実際に数えたもの。
**変わったら台本も直す。** 確認コマンドは `node tools\validate.mjs`（語数・編数が出る）。

| 項目 | 数 | 出どころ |
|---|---|---|
| 古文単語 | **330 語** | `data/words.js` |
| 重要度の内訳 | **S 最重要 114／A 頻出 111／B 応用 105** | 同上 |
| 文章（教材） | **44 編** | `data/passages.js` |
| 段落 | 179 段落 | 同上 |
| 作品 | **30 作品** | `data/works.js` |
| うち共通テスト・センター試験の出典作品 | 16 作品 | `works.js` の `exam` つき |
| 入試の出典から採った文章 | 7 編 | `passages.js` の `exam` つき |
| 品詞分解 | **44 編すべて**（1 編も欠けていない） | `data/tokens/*.js` が 44 ファイル |
| 古典文法 | **5 分野・149 項目**（助動詞 29・助詞 56・敬語 38・活用 13・識別 13） | `data/grammar.js` |

言っていい売り文句：

- **無料**・**登録なし**・**ダウンロード不要**（ブラウザで開くだけ）
- **学習履歴は端末の中だけ**。どの語を覚えたかはサーバーに送らない
- **ホーム画面に追加**すればアプリみたいに使える（オフラインでも読める）
- 文法の**用例は全部、収録した教材の原文**（作例じゃない）
- 現代語訳はこのアプリのための書き下ろし。**試験の設問・注・リード文は載せていない**

> 注意：README.md の「教材 27 編」「作品 12 件」は古い記述。実データは 44 編・30 作品。

どれも **画面はいきなり本文タップの瞬間から始める**（ロゴやタイトルから始めない）。

| 案 | セリフ（ナレーション） | テロップ | 狙い |

## 2. 30 秒版 台本

尺配分：フック 2 秒 → ①品詞分解 7 秒 → ②文章クイズ 6 秒 → ③スワイプ 5 秒 → ④文法ドリル 5 秒 → 締め 5 秒。

**順序の理由**：いちばん珍しくて 1 秒で伝わる「タップ→品詞分解」を先頭に置く。
そのあと「読む → 解く → 覚える → 文法」で勉強の流れの順に並べると、
説明しなくても使い方が分かる。

| 秒数 | 画面（何を映す／操作） | ナレーション | テロップ |
|---|---|---|---|
| 0:00–0:02 | `#/passage/makura-haru` の 1 段落目にもう指を置いた状態から開始。「やうやう」をタップして品詞分解ポップアップが出る | 古文の単語、タップしたら意味出る | **タップで意味出る** |
| 0:02–0:05 | ポップアップを 1.5 秒見せる（品詞・活用の種類・活用形・意味）。閉じて別の語「たなびきたる」をタップ | 品詞も、活用も、意味も出る | **品詞・活用・意味** |
| 0:05–0:09 | 助動詞「たる」をタップ →「文法：「たり」（存続）の解説へ →」のリンクを指でさす。上にスクロールして原文全体が青い線だらけなのを見せる | どの語でもいい。全部入ってる | **44編ぜんぶ品詞分解** |
| 0:09–0:12 | 本文の下まで一気にスクロール →「この文章の単語でクイズ」をタップ → 出題形式の画面が出て「はじめる」 | この文章に出た単語だけでクイズ | **この文章の語だけ** |
| 0:12–0:15 | 4 択を 2 問、指でタップ。○ が出る。1 問わざと間違えて × も見せる | 4択。まちがえた語は苦手に入る | **まちがえたら苦手へ** |
| 0:15–0:18 | `#/study?level=S` のフラッシュカード。表をタップしてめくり、裏を**右にスワイプ** | カードは指で払うだけ | **右＝覚えた** |
| 0:18–0:20 | もう 1 枚、**左にスワイプ**（赤い「まだ」ラベルが濃くなる） | 覚えたは右、まだは左 | **左＝まだ** |
| 0:20–0:25 | `#/grammar/drill` →「はじめる」→ 1 問答える（「この『なり』はどの意味？」のような 4 択。○ と根拠が出る） | 文法も、10問のドリルで確認 | **文法ドリル 10問** |
| 0:25–0:28 | `#/` ホームに戻り、330 語の進捗バーと「続きから」を見せる | 無料。登録もいらない | **無料・登録なし** |
| 0:28–0:30 | ホーム上部で静止。制作者行「制作：雨峰あまね」が見える | リンクはプロフィールとコメント欄に | **リンクはプロフ／コメント欄**<br>（小さく）**雨峰あまね** |

## 4. 画面収録の手順書

### 4-1. 収録の設定

| 項目 | どうする | 理由 |
|---|---|---|
| 向き | **縦のまま固定**（画面の自動回転をオフ） | 途中で横になると使えない素材になる |
| 音 | **マイクはオフ**（無音で録る） | 部屋の音が入る。ナレーションと BGM は後で足す |
| 配色 | **ライトモード**（OS のダークモードはオフ） | このアプリは OS のダークモードに追従する。暗い画面は縮小表示で読めない |
| 文字サイズ | OS の文字サイズは**標準**。ブラウザのズームも 100% | 大きすぎるとレイアウトが崩れ、小さすぎると読めない |
| 通知 | **集中モード／サイレント**をオン。Wi-Fi は繋いだまま | 通知バナーが映ると全部撮り直し |
| バッテリー | 50% 以上で、低電力モードはオフ | 赤い電池アイコンや黄色いステータスバーが映る |
| 時計 | **ステータスバーは映っていい**（隠さない）。ただし時刻はキリのいい時間を避ける | 実機で撮った感じが出るほうが信用される |
| ブラウザ | **ホーム画面に追加した状態（スタンドアロン）で撮る** | アドレスバーが消えて画面が広く、アプリらしく見える。URL を映したいカットだけ Safari / Chrome で撮る |
| フレームレート | 既定のまま（60fps が録れるならそのまま） | スワイプとポップアップの動きが滑らかに見える |

**iPhone**：設定 →コントロールセンター →「画面収録」を追加 →コントロールセンターの録画ボタンを**長押しして「マイク」をオフ**にしてから開始。
**Android**：クイック設定の「スクリーンレコード」→「音声を録音」を**オフ**、「画面上のタップを表示」は**オフ**（青い丸が邪魔になる）。

### 4-2. 収録前のリセット（きれいな状態にする）

進捗バーが中途半端に埋まっていたり「続きから」に前回の履歴が出ていると、
画面がごちゃついて説得力が落ちる。**撮る直前に必ずやる。**

1. `https://amemineamane.github.io/kobun-tango/#/help?to=history` を開く
2. 「学習履歴について」の節の **「学習履歴をリセットする」** を押す
3. 確認のボタンが出るので、もう一度押す（2 段階。覚えた・苦手の記録、クイズと文法ドリルの履歴、「続きから」が消える）
4. `#/` を開いて、進捗バーが空で **「まず S 最重要の 114 語から」** の案内が出ていることを確認
5. `#/passage/makura-haru` を開いて、**「訳を表示」「上下に並べる」**（＝既定の状態）になっていることを確認。
   前回いじっていたら押して戻す（この設定はブラウザに残る）

> リセットしたくないとき（自分の進捗を消したくない）は、**プライベートウィンドウ**で開いて撮る。
> localStorage が使えないと上部に注意バーが出るので、**その 1 行が映らない構図で撮ること**。
> 確実にきれいに撮りたいなら、素直にリセットするほうが早い。

| 14 | 30/60 | `#/grammar/drill` | 「はじめる」→ 1 問目に答える（○ と根拠が出る）→ 2 問目も答える | 10 秒 |

| 17 | 予備 | `#/word/39` | 単語詳細（`をかし`）。関連語カードと「この語が出てくる文章」（※単語帳として見せたいとき用） | 6 秒 |

**共通のコツ**

- 1 カットは **必要な長さの 2 倍**撮る。編集で頭と尻を落とすと動きが気持ちよくなる
- タップは**指を止めてから押す**。指が横切るだけのフレームは編集で使えない
- スクロールは**指 1 本でゆっくり**。慣性で飛ぶと何も読めない
- ポップアップは**出てから 1.5 秒は動かさない**（縦動画では読む時間が要る）
- 同じカットを **3 回**撮る。押し間違い・通知・指の影で 1 回では必ず失敗する
- `#/quiz` の 4 択は毎回選択肢が変わるので、**気持ちよく正解できた回だけ採用**する

### 5-3. 字幕の見せ方

- 位置は**下から 22%**（TikTok と YouTube ショートの UI に隠れる下 15% は空ける）
- 白文字＋黒フチ（2〜3px）か、黒の半透明帯。**背景が原文の縦長テキストなので、フチなしは読めない**
- **1 行 15 字前後で 2 行まで**。3 行になったら文を切る
- 書体はゴシック（游ゴシック Bold / Noto Sans JP Bold）。**明朝は使わない**
  （アプリの原文が明朝なので、テロップまで明朝だと画面が全部同じ顔になる）
- 数字（330・44・149・16）だけ**色を変える**か少し大きくする。数字が伝わると信用される

## 6. BGM / 効果音の方針

**全体**：テンポ速め。**110〜130 BPM のローファイ・ヒップホップか軽いピアノ系**。
勉強アプリなので、盛り上がるトラックより「作業中に流れてる感じ」が合う。
歌もの・ボーカル入りは字幕と競合するので使わない。

| 用途 | 音 | 音量（BGM を 0dB としたとき） |
|---|---|---|
| BGM | ループ 1 本で通す。**サビや転調が来ないループ**を選ぶ | −18〜−20dB（ナレーションの下） |
| タップ音 | 短くて軽い「ポッ」「トッ」。**原文の語をタップした瞬間に必ず入れる**。これが動画の主役 | −6dB |
| ポップアップ | ふわっと開く「シュッ」。タップ音の 0.1 秒後 | −10dB |
| スワイプ | 紙が飛ぶ「シャッ」。右と左で**同じ音**でいい | −8dB |
| 正解（○） | 明るい 2 音「ピンポーン」ではなく、短い「ピッ」 | −8dB |
| 不正解（×） | 低く短い「ブッ」。**強く鳴らさない**（責められてる感じが出る） | −14dB |
| 締め | フックと締めだけ BGM をワンフレーズ上げる | — |

- 素材は**商用利用可・クレジット不要**のフリー素材で揃える（効果音ラボ、DOVA-SYNDROME など）。
  使った素材の名前と URL は `docs/promo/` にメモしておく
- **TikTok は公式の楽曲ライブラリから選ぶほうが伸びる**。YouTube ショート用と TikTok 用で BGM を差し替え、
  効果音とナレーションは共通にする（そのために BGM は別トラックで書き出す）
- ナレーションは **−3dB 前後**で、BGM にダッキング（ナレーション中だけ BGM を 6dB 下げる）をかける
- 無音でも成立するように作る。**音を出さずに見る人が半分いる**ので、テロップだけで意味が通ること

## 9. NG 事項

作る前と出す前に、毎回ここを読む。

| やらないこと | 理由 |
|---|---|
| **試験問題の画像・設問文・リード文・注を映さない／書かない** | 著作権。アプリ側も設問・注・リード文は載せていない。映していいのは**アプリが表示している原文・現代語訳・品詞分解・出題バッジだけ**。共通テストの冊子・過去問集・予備校の解説を撮るのも駄目 |
| **「必ず受かる」「これだけで満点」「偏差値が上がる」と言わない** | 結果を断定できない。言えるのは「原文が読める」「その文章の語だけで演習できる」のような**機能の説明**まで |
| **「共通テスト対策アプリ」「公式」と名乗らない** | 試験の主催団体と関係があるように見える。言い方は「**共通テスト・センター試験の出典作品を収録**」まで |
| **他社アプリ・書籍・予備校を名指しで比べない** | 「○○より使いやすい」「紙の単語帳はもう要らない」も駄目。**自分の機能だけを話す** |
| **他社アプリの画面を映さない** | 比較として並べるのも駄目 |
| **学習履歴・進捗の画面に個人情報は出ない** | このアプリはログインもアカウント登録もなく、名前・メールアドレス・学校名を入力する欄がひとつも無い。進捗の画面に出るのは語数と割合だけなので、**そのまま映して問題ない**。逆に「個人情報を預けなくていい」は言っていい売り文句 |
| **自分の画面のステータスバーに通知や個人名が映らないよう確認** | アプリは個人情報を出さないが、**端末のほうが出す**。撮ったあと必ず 1 コマずつ確認する |
| **「オフラインでも全部使える」と言わない** | 正しくは「**一度ひらいたページは**オフラインでも読める」。未訪問のページは開けない |
| **「データは完璧」と言わない** | 原文は底本によって異同があり、解釈が分かれる品詞分解には画面上で「要確認」が付いている。**「解釈が分かれるところは印を付けてある」と言うほうが正直で、むしろ信用される** |
| **AI で作ったことを隠す／ことさら強調する、どちらもしない** | 訊かれたら答える。動画では機能の話に集中する |
| **フォロー・いいねを煽らない** | 「保存しないと損」「フォローしないと見れない」はプラットフォームに嫌われる。**「リンクはプロフィールとコメント欄」だけ言う** |
| **コメント欄のリンクを貼り忘れない** | 投稿直後に自分で固定コメントを打つ。これを忘れると全部の流入が死ぬ |
